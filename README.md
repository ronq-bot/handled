# Idol Squad: Brainrot Defense

An idle tower-defense shooter: a squad of K-pop-style idol monster hunters
defends their stage barrier against waves of absurd brainrot-style monsters.
Swipe the ammo belt to slice bullets into ammo, pick upgrade cards as you
level up, and take down giant bosses.

All characters, art (drawn procedurally in code) and audio (synthesized at
runtime) are original — there are no third-party assets to license.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173 — use your browser's phone emulation
npm run build    # production bundle in dist/
```

See `ROADMAP.md` for progress toward App Store submission.
